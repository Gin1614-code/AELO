# First Then Auto - 树莓派直接运行包

## 启动文件

`first_then_auto.py`

## 安装与运行

**1.** 将 `first_then_auto.py` 复制到：

`/home/lemon/catkin_ws/src/aelos_smart_ros/contest_code/botec/`

**2.** 在树莓派终端中运行：

```bash
cd /home/lemon/catkin_ws/src/aelos_smart_ros/contest_code/botec/
python first_then_auto.py
```

**如果机器人上的 `python` 命令指向 Python 2，请改用：**

```bash
python3 first_then_auto.py
```

**无需修改树莓派的区域设置或编码设置。**
源码文件只包含 ASCII 字节，因此 UTF-8/GBK/GB18030 传输转换不会破坏其中文运行时提示信息。

## 程序行为

- **第 1 轮** 保留 **firstauto3.9** 视觉取箱路线。
- **第 2 轮及之后每一轮** 保留 **auto3.5** 固定取箱路线。
- **每轮开始时**，输入 `1` 使用不带前缀的单物块运动动作组，或输入 `2` 使用带 `x_` 前缀的双物块动作组。
- 选定的运动动作组**在该轮内固定**，可覆盖路线轮次：第 1 轮可使用动作组 2，后续轮次可使用动作组 1。
- **无效的终端输入不会启动任何机器人动作。** 每一新轮都会在动作前重新询问一次 `1` 或 `2`。
- **轮次之间没有 10 秒延迟。**
- **保留原有的 3 秒轮次重置。**
- **Marker 1** 使用 **Y 目标中心 -0.010 m**。其 **0.140 m 准入半宽**不变，因此接受的 Y 范围为 **-0.150 至 0.130 m**。
- **Marker 2**：最后观测到的 **X 距离大于 0.165 m** 表示机器人仍然太远。若此时标记丢失，机器人继续执行原有的前进盲搜动作，而不是假定已完成。
- **Marker 2** 仅在最后观测到的 **X 距离 ≤ 0.165 m** 时，才可使用 **0.6 秒丢码完成规则**。
- **Marker 3**：角度误差**严格大于 15 度**时触发原有的 **30 度左转**动作。Marker 3 的其他限制不变。
- **Marker 4**：每次对准动作后，机器人最多等待 **0.8 秒**以获取新的 Marker 4 观测。此期间看到其他标记不会立即触发前进盲搜动作。
- 若 Marker 4 最后观测到的 **X 大于 0.360 m**，且在观测等待后仍然丢失，机器人**前进 2 步**并再次等待。
- 若 Marker 4 最后观测到的 **X 大于 0.270 m 但不超过 0.360 m**，机器人仅**前进 1 步**并再次等待。
- **Marker 4 的 X 为 0.270 m 或更小时，禁止盲目前进。** 丢码完成还要求**角度在 5 度以内**且 **Y 不大于 0.150 m**；否则机器人保持不动以等待重新识别。
- 若 **Marker 4 从未被看到**，保留原有的**前进 3 步**盲搜逻辑。
- **Marker 4** 对准完成后，机器人执行 **3 次大步左横移**、**右转 10 度**、**前进 1 步**，然后切换到 **Marker 5**。
- **Marker 5** 对准完成后，机器人**左转 30 度**、**前进 4 步两次**，然后**放下箱子**。
- **Marker 1、3、5** 保留已确认的 **0.6 秒完成规则**。
- 若某标记**从未被看到**，保留原有的盲搜逻辑。
- **不使用**自动标定、JSON 参数加载或自学习。
